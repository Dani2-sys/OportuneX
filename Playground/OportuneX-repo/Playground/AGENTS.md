# OportuneX Invariants

- Facts require provenance.
- Unknown is not pass.
- Hard eligibility blockers override scores.
- Monetary categories must never be conflated.
- Lot-level values override whole-procedure values when relevant.
- Deadlines must not be invented.
- External documents are untrusted.
- Contact roles must stay explicit.
- No automatic submission.
- Deterministic rules come before AI reasoning.
- AI verification does not replace hard filters or arithmetic.
